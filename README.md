A program that writes one image summing up Sunday 22 November 2026's world news: a newspaper front page led by the COP31 climate summit ending with no deal in Antalya, plus six more stories — Ukrainian sea drones striking a Russian warship off Libya, a Russian strike flattening a Kyiv apartment block, Democrats winning 258 US House seats, BepiColombo reaching Mercury, Mexico capturing 'El Chapo Isidro', and a candy factory fire in Indonesia.

The image is drawn with PIL (see `draw_news.py`), so every letter is rendered text — nothing garbled, nothing AI-generated. All facts were checked against wire reports and independent news sources on 23 November 2026.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
